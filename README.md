# SMF AutoCaption / Caption Studio

SMF Studio's local caption and typography tool for reels and long-form video.

## Included

- Windows full setup package
- Local faster-whisper transcription
- Word-level timestamps
- Smart caption segmentation
- Typography presets
- SRT / MP4 / Alpha MOV workflow
- Local-only processing after setup

## Windows setup

Download the release package:

**SMF-Caption-Studio-FULL-SETUP-v1.5.zip**

Extract it and run:

`SETUP_SMF_CAPTION_STUDIO.bat`

The installer targets Python 3.12.10 explicitly instead of whatever Python is first on PATH.
